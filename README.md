# Basketball National Team Website

## Overview

This project is a responsive website dedicated to a national basketball team, developed using Bootstrap. The website provides information about players, matches, achievements, and the history of the team through a modern and user-friendly interface.

## Features

* Responsive design for different screen sizes
* Player profiles and team information
* News and updates sections
* Online ticket purchasing
* Team statistics and performance data
* Clean and structured layout using Bootstrap components

## Technologies Used

* Bootstrap
* CSS

## Description

The website presents information about a national basketball team, including player details, match schedules, results, achievements, and general team history. The focus of the project was on creating an attractive, responsive, and easy-to-navigate sports website.
